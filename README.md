 FinAngel: The AI Guardian for Vulnerable Banking

Submitted for the "Innovation Unbound" Hackathon 
Theme: AI for Financial Inclusion and Social Impact  
Team Members: Rohin Kumar & Nishant Sinha.  
Development Method: 100% Vibe-Coded via Google Antigravity & Base44


The Vision:-
Traditional bank security is built to stop system hacks, not psychological manipulation. Modern scammers use AI to generate high-urgency, fear-inducing social engineering traps (fake utility bills, lottery scams) that target vulnerable citizens—like senior citizens and digitally inexperienced users. 

FinAngel is an empathetic AI guardian integrated directly into the banking/UPI pipeline.** Instead of displaying rigid technical error codes, it reads the room, intercepts manipulative fraud *before* the PIN screen, and communicates reassurances to users in their local Indian languages.


Core Innovations & Features:-
Psychological Intent Detection: Moves beyond static rules to evaluate text tone, checking for artificial urgency, panic triggers, and impersonation tactics.
Vernacular Audio Alerts: Translates technical risk assessments into warm, comforting spoken guidance in multiple Indian languages (Hindi, Tamil, Telugu, etc.) for elderly users.
Pre-PIN Interception Pipeline: Uses a secure foreground API gateway to freeze transaction ledgers before a user can accidentally compromise their account.
Closed-Ones Emergency Dashboard: Displays trusted family contact information instantly, requiring a secondary confirmation if a high-risk transaction is flagged.

 The Tech Stack (Vibe Coding Framework)
Our prototype architecture combines human logic engineering with agentic software assembly:
1.Core AI Engine ('core_ai_engine_v1.py'): Our foundational logic loop that evaluates message payloads using highly specific JSON-structured LLM system prompts.
2. Full-Stack Application ('main_app.py'): A 600+ line production-ready environment complete with a Python server and an interactive HTML/JS front-end sandbox, compiled autonomously by Google Antigravity.
3.Data Layer Architecture: Leverages Base44 formatting guidelines to securely append contextual notification data to transaction payloads.
